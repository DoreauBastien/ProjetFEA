Note à connaitre pour le rendu en classe 

Si l'on ne lance pas via le --cas, le code choisit de base les données de l'exemple du projet. 

Pour avoir les étapes de calculs plus précises que les simple résultats finaux : 
    python -u "/Users/bastiendoreau/Desktop/A4/S1/Finite element analysis/ProjetFEAGithub/Projet/ProjetFEA.py" --details

Dans les détails: 
    1) Coord(m) donne la positions de chaque points (dans l'ordre)
       Connec indique les extrémités de chaque barre en fonction des neuds (ils sont numérotés). A=0 ; B=1 ...  donc la première barre fait [0 1] de A à B 
       On a le module d'Young et la section. 

    2) Longueur et angles 
    
    3) Matrices de rigidité par barre puis matrice de rigidité globale. 

    4) Blocage des déplacements [0 0] déplacement autorisé (A dans l'exemple), [1 1] aucun déplacement.
       Forces nodales
       Matrice de rigidité réduite
    
    5) Déplacement

Comment remplir le json : (json accepte pas les commentaires)

{
  "coord": [[0, 0], [3, 0], [3, 2],[0, 2]],    // Coordonnées des nœuds
  "connec": [[0, 1], [0, 2],[0, 3],[1, 2],[2,3]],    // Connexions des barres
  "module": 210000000000,               // Module d'Young
  "diametre": [0.020, 0.018, 0.012, 0.016, 0.014],    // Diamètres des barres en m
  "liaisons": ["bloque", "libre", "libre", "libre_y"], // Liaisons aux appuis (bloque = déplacement nul, libre_x = déplacement libre en x, libre = déplacement libre en x et y)
  "val_f": [[0, 0], [600, -800], [0, -1000], [0, -1000]] // Forces nodales en N
}
